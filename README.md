# Replay Board

Студия интерактивных объяснений на доске. Автор записывает создание и перемещение
объектов, зритель воспроизводит историю, перематывает и исследует схему на паузе.

Реализован этап P1: локальный проект, SVG-доска, запись без голоса, воспроизведение,
автосохранение в IndexedDB и восстановление после перезагрузки.
Есть два линейных примера, созданных общим recorder, и возможность редактировать свою копию.
Стрелки прорисовываются, текст набирается по времени истории. Пауза и перемотка
сохраняют промежуточный вид; начальные надписи уже готовы. Уменьшенное движение
отключает эффекты, сохраняя сами команды. Обновлены главная, проигрыватель и инструменты студии.

[Смотреть видеодемо в портфолио](https://github.com/alexsashka1771#replay-board).

## Запуск

Нужны Node.js 24 и npm 11. Docker и внешние сервисы не требуются.
Команды выполняются из корня проекта в PowerShell 5.1:

```powershell
npm.cmd install
npm.cmd run dev
```

Приложение: [http://127.0.0.1:5173](http://127.0.0.1:5173).
Черновики хранятся в этом браузере; другие вкладки не могут незаметно перезаписать свежую версию.

## Первый сценарий

1. Создайте историю, добавьте блоки, текст и связи.
2. Нажмите «Записать» и изменяйте доску.
3. Остановите запись, дождитесь «Сохранено», откройте «Просмотр».
4. Перемотайте или остановите историю для исследования; перезагрузите страницу для восстановления проекта.

Клавиши редактора: B — блок, T — текст, C — связь, V — выбор, Delete — удаление;
Ctrl+Z / Ctrl+Shift+Z — отмена/повтор. Пробел с перетаскиванием перемещает доску.
В проигрывателе пробел запускает/останавливает историю.

## Проверки

```powershell
npm.cmd run build
npm.cmd run lint
npm.cmd run test
npx.cmd -y playwright install chromium
npm.cmd run test:e2e
```

E2E проверяют desktop-редактор и просмотр на мобильном viewport Chromium.
Четыре авторских сценария (создание, восстановление, конкурирующие вкладки и вписывание
с инструментами) намеренно пропущены на мобильном устройстве. Живой просмотр,
перемотка, reduced motion и фокус с клавиатуры проверяются на обоих viewport.
Последний пакет скриншотов: `artifacts/visual/live-confirm/`. Отчёт Playwright: `playwright-report/`.
Весь набор одним вызовом: `powershell.exe -NoProfile -File ".\scripts\verify.ps1"`.
