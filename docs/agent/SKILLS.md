# Replay Board: навыки проекта

Профиль связывает задачи с установленными навыками. Источники проверены 24.11.2026.
Полный SKILL.md читается при совпадении условия; весь справочник не загружается на каждом шаге.
Навигация: [AGENTS.md](../../AGENTS.md), [PLAN.md](PLAN.md).

`~/` означает каталог пользователя, доступный в PowerShell как `$env:USERPROFILE`.
Локаторы ниже не являются путями от корня проекта. На другой машине нужны соответствующие
пользовательские/system-навыки; копии уже установленных навыков в проект не создаются.

Для багов сохраняется требование пользователя написать воспроизводящий тест до фикса.

## Разделение пересекающихся навыков

- frontend-design отвечает за создание экранов в согласованной студии;
  impeccable подключается для целевой доводки и аудита, а не запуска всех его режимов.
- impeccable находит PRODUCT.md в docs/; не нужно создавать вторую спецификацию в корне.
  Его context loader запускается один раз в сессии только при применении навыка к UI;
  craft-floor читается перед изменением UI, не для текущей документационной задачи.
- writing-plans уточняет выбранный этап. Текущий phased plan не содержит выдуманного
  application-кода и выводов ещё не существующих тестов.
- Проектный E2E-runner — Node Playwright; Python-helper webapp-testing доступен для отдельных проверок.
- Навыки не дают отдельного разрешения на коммит, push, деплой или смену согласованных требований.
  При конфликте действует запрос пользователя и иерархия инструкций.

## Дополнительные и отложенные

Специальный навык SVG-recording/audio-timeline не требуется: контракт задают PRODUCT.md и ARCHITECTURE.md,
а неизвестные API проверяются по официальной документации/Context7.
Навык хостинга будет выбран после явного запроса интернет-деплоя и решения о провайдере.
Supabase, Stitch, библиотеки анимации и генерация изображений в текущий выбранный стек не входят.

## Проверка и установка

При реализации P1 применены выбранные процессные/UI/React-навыки, TDD, debugging,
браузерные проверки, независимое ревью и проверка его замечаний.

Существование двенадцати SKILL.md и их точные имена проверяет
[verify-context.ps1](verify-context.ps1). Это проверка источников, а не оценка поведения навыков.
Node/Python и зависимости приложения доступны; Chromium установлен. Аудиокодеки и WebKit ещё не проверены.
Context7 исчерпал месячную квоту после проверки основных библиотек;
до восстановления доступа использовать официальные документы и документацию установленных пакетов.
Impeccable отметил старый служебный формат PRODUCT.md; его init выполняется только по отдельному запросу.
Установки навыков, hooks и глобальные настройки агентов в этой сессии не изменялись.
